# muse-test

A playground for experimenting with [Meta Muse](https://muse.ai) — a personal AI agent that can delegate work, automate routines, and build things.

## Purpose

This repository is where I try out Muse's capabilities in practice: handing off real tasks, testing integrations, and seeing what works (and what doesn't).

## How it's organized

- `experiments/` — one folder per experiment, each with its own write-up
- Each experiment documents the goal, what was tried, and what was learned

## Running an experiment

1. Pick a capability to test (e.g., scheduled tasks, web research, artifact building)
2. Give Muse a task and observe what it does
3. Write up the result in `experiments/<name>/README.md`
